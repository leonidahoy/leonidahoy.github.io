Heads-up

Some physical boxes reveal the code with a flashlight

Saturday, November 14, 2026

VideoCardz reports that on certain physical editions (which are a code in a box) the download code can be read without opening it. Tests on US and UK copies failed; some European ones may be less protected.

In plain words

If you buy the boxed edition, get it from a store you trust and check the code works as soon as you open it.

The details

The physical edition has no disc, just a download code inside the box. According to VideoCardz, on some packaging the code shows through when you shine a light on it. It didn't work on the US and UK copies that were tested.

Why it matters

A code that can be read without opening the box could be redeemed by someone else before the buyer.
